# Contributing

Contributions must preserve this project's independent implementation boundary.

Before submitting code:

1. Read `AGENTS.md` and the documents under `docs/`.
2. Explain the user-visible or interoperability problem.
3. Record the source of each new protocol rule in `docs/provenance.md`.
4. Confirm that the contribution does not copy or translate GPL-covered code,
   comments, structure, or tests.
5. Add focused tests for malformed input, limits, cleanup, and compatibility.
6. Run the formatting, Clippy, and test commands from `README.md`.

By contributing, you agree that your contribution is licensed under
`MIT OR Apache-2.0` and that you have the right to provide it under those terms.
