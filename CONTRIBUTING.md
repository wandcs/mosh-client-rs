# Contributing

Contributions must preserve this project's independent implementation boundary.

Before submitting code:

1. Read `AGENTS.md`, `docs/project-principles.md`, and the applicable documents
   under `docs/`.
2. Explain the user-visible or interoperability problem.
3. Explain how the change follows the project principles and complexity gate.
4. Record the source of each new protocol rule in `docs/provenance.md`.
5. Confirm that the contribution does not copy or translate GPL-covered code,
   comments, structure, or tests.
6. Add focused tests for malformed input, limits, cleanup, and compatibility.
7. For a dependency change, update `docs/dependency-assessment.md` and run the
   license and advisory checks in `docs/testing.md`.
8. Run the formatting, Clippy, and test commands from `README.md`.

By contributing, you agree that your contribution is licensed under
`MIT OR Apache-2.0` and that you have the right to provide it under those terms.
