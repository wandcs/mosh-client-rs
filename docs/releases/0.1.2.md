## Release decision

This reliability release retains valid U+FFFD and representative printable
Unicode in authoritative terminal state and synthesized VT output. It rejects
DEL explicitly instead of silently dropping it after text. Malformed UTF-8 and
unsupported controls still fail. The public Session API and resource limits do
not change. The private terminal model includes a scoped, licensed copy of
`vt100` 0.16.2 so the source package carries the one-line U+FFFD correction.

## Verification

Rust verification commands ran in the default WSL distribution at
`/mnt/c/repos/mosh-client-rs`. Stable 1.96.0 and Rust 1.88.0 passed formatting,
strict Clippy, and the all-target/all-feature suite: 147 ordinary tests passed
and 24 environment-dependent stock fixtures were intentionally ignored by the
ordinary run. All 24 stock Mosh 1.4.0 fixtures then passed serially, including
valid U+FFFD, server replacement of an invalid remote byte, selected Latin,
CJK, emoji, and combining text, later input, resize, and full repaint.

`cargo deny check`, the cached `cargo audit` scan, rustdoc on Rust 1.88.0, and
the ARM64 HarmonyOS release library build passed. Stable Cargo packaged the
clean tagged tree and verified the unpacked source. The unpacked package also
compiled offline with Rust 1.88.0. Cargo 1.88.0 generated the `.crate` on the
WSL-mounted repository but failed its immediate metadata readback twice; the
stable package verification and independent Rust 1.88.0 unpacked build supplied
the package and minimum-version checks.
