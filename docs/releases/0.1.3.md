- Review date: 2026-09-25.
- Package: `mosh-client` 0.1.3, MIT OR Apache-2.0.
- Minimum Rust version: 1.88.0.
- Release channel: annotated `v0.1.3` Git tag and GitHub Release with the
  inspected source package and SHA-256 checksum. No crates.io upload.
- Status: release candidate; publication and consumer readback pending.

## Release decision

This reliability update uses one stock-server cell-width policy for terminal
validation, authoritative screen cells, cursor placement, and VT paint. It
fixes the U+0605 `Protocol` disconnect and covers the 95 finite-width
differences observed between `unicode-width` 0.2.2 and the stock fixture's
`C.UTF-8` glibc profile. It retains malformed UTF-8, unsupported-control,
eight-scalar, and cell-byte rejection. The public Session API, wire format,
production dependencies, and resource limits do not change.

The versioned compatibility profile is documented in the
[cell-width fixture](../fixtures/stock-1.4.0-cell-width.md). Representative
characters, not all code points or server locales, were exercised through
stock `mosh-server` 1.4.0.
